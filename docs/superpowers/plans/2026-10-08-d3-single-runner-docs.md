**Goal:** привести документацию в согласие с решением владельца D3: direct-runner
(ADR [0027](../../adr/0027-advisory-ai-direct-local-runner.md), Accepted) единственный
боевой путь ИИ-разбора; Docker и relay остаются харнессом для экспериментов и приёмок.

**Architecture:** только Markdown. В ADR (история решений) прошлое не переписывается:
добавляется короткая пометка «Обновлено решением D3 / ADR 0027» со ссылкой. В
пользовательской инструкции обновляется порядок запуска.

**Tech Stack:** Markdown, markdownlint-cli2, lychee.

**Spec:** строка D3 в `docs/superpowers/plans/2026-10-08-review-work-plan.md`; ADR 0027.

## Rulings

- Ruling: код по умолчанию (переменная не задана) идёт путём Docker, поэтому в
  пользовательской инструкции не пишется «direct включён по умолчанию»; пишется, что
  боевой путь direct, он включается `LT_VERDICT_AI_RUNNER_MODE=local`, как в README и ADR 0027.
  Цена ошибки: оператор решит, что direct уже по умолчанию, и получит `UNAVAILABLE`
  или запуск Docker.
- Ruling: раздел direct в `advisory-ai.md` не переносится (наименьший дифф); порядок
  запуска задаётся введением, раздел только переименовывается из «Proposed» в «Accepted».
  Цена: читатель дойдёт до него позже Docker-разделов; смягчается ссылкой из введения.
- Ruling: Codex Astra по плану не запрашивается: PR только текстовый, контракты и код
  не затрагиваются, шаг дал бы мало. Цена ошибки: пропущенная формулировка;
  смягчается повторным grep.

## Приёмка и проверки

  относительных ссылок вручную) по изменённым файлам без битых ссылок.
- Документация: `Documentation impact:` есть в теле PR; changelog не нужен (нет путей
  src/main, ui/src, docs/contracts, tools).
