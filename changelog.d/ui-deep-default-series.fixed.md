- «Глубокий анализ» новой оболочки: ряды по умолчанию теперь выбираются в
  порядке «ряды непройденных правил, затем остальные ряды ресурсов роли
  `system` по алфавиту, затем ряды роли `generator`». Раньше ряды генератора
  нагрузки могли вытеснить ряд ЦП сервиса из шести отмеченных (в демо-сценарии
  насыщения ряд `service-cpu-busy` приходилось отмечать вручную). Ряды
  непройденных правил по-прежнему идут первыми; порядок на экране следует за
  порядком выбора. Лимит в шесть рядов, API, ядро и серверные контракты не
  менялись.
