- Совет ИИ-разбора: повтор запроса при ошибке схемы (ADR 0021, Д2) снова
  срабатывает на реальном провайдере. Relay сравнивал `arguments` продолжения со
  строкой из потока побайтно, а провайдер (DeepSeek через ModelStudio) присылает
  JSON с пробелами после `:` и `,`, тогда как Qwen Code возвращает его компактно:
  продолжение отклонялось как `RETRY_CONTINUATION_MISMATCH`, и повтор почти не
  срабатывал. Теперь `arguments` принимаются, если совпадают с потоком либо равны
  компактной записи того же разобранного JSON (`JSON.stringify(JSON.parse(...))`);
  другой порядок ключей, иные пробелы и экранирование, повторяющиеся ключи, иная
  запись числа и любое изменение значения, в том числе внутри строки-обёртки,
  по-прежнему отклоняются. Число запросов к провайдеру на совет не больше двух.
  Кроме того, relay записывает первую причину отказа в повторе в
  `relay-result.json` (новое поле `first_refused_reason`): раньше её затирало
  `RETRY_LIMIT_REACHED`, когда Qwen продолжал слать запросы. Поле аддитивное,
  `schema_version` результата relay, API, схемы и ядро не менялись; launcher и
  Kotlin поле не читают.
