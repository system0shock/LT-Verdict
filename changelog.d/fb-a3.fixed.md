- Для `CREDENTIAL_NOT_CONFIGURED` ИИ-разбор показывает имя настройки, путь
  credential-файла и причину недоступности. Значения `LT_VERDICT_AI_CREDENTIAL_ENV_FILE`,
  начинающиеся с `~/` или `~\`, теперь раскрываются через `HOME`
  (на Windows: `HOME`, затем `USERPROFILE`); нечитаемый credential-файл
  теперь диагностируется до запуска runner. HTTP status дополнен полем `detail`, которое отображается в UI;
  прежний код причины сохранён, значения секретов не выводятся.
