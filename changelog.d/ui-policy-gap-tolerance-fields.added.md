- Редактор политики на вкладке «Правила» показывает и меняет допуск пропусков
  `defaults.max_missing_fraction` (доля `0 <= x < 1`) и `defaults.max_gap_cells`
  (целое `0..100000`) (ADR 0018, срез S7): поля «Допустимая доля пропусков» и
  «Допустимый разрыв, ячеек» под минимумом выборки. `0` сохраняется как значение,
  пустое поле удаляет ключ, границы проверяет сервер (`TOLERANCE_OUT_OF_RANGE`).
  Значения действуют только на платформенные `sla`-правила; правило покрытия реплик
  остаётся строгим независимо от них. Сами `platform_rules` редактор по-прежнему не
  показывает: они сохраняются при правке, допуск отдельного правила задаётся в
  файле политики. Прежний интерфейс (`?shell=old`), API, ядро и контракт политики не
  менялись.
