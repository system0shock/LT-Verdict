- «Сравнение»: подсказка при `INCOMPATIBLE_METRIC_DEFINITION` и
  `BASELINE_MIXED_SEMANTICS` больше не обвиняет только «старые правила
  анализа». Она называет обе причины несопоставимости: разный набор данных
  (снимок ресурсов и правила по ресурсам, диагностика, ёмкость, тренды) или
  разные версии правил анализа. Кнопка «Сохранить решение об условиях» больше не
  убирает результат сравнения с экрана: показанное сравнение повторяется само,
  строка статуса обновляется. API и ядро не менялись.
