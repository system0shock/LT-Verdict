- Блок «Ёмкость по ступеням» на «Обзоре» нового интерфейса для теста максимума:
  итог словами, граница ёмкости словами с единицами, фраза о том, как граница
  стоит относительно требуемой ёмкости (числа требования в результате нет, фраза
  выводится из вердикта: при `PASS` требуемая не выше нижней границы, при `FAIL`
  не ниже верхней), полосы нагрузки по ступеням с линиями границ и таблица тех
  же значений как текстовый эквивалент. Итог ступени дублируется значком и
  словом, цвет не единственный признак; ступень с малой выборкой помечена.
  Кнопка «Открыть ёмкость» ведёт на вкладку «Таблицы». Для результатов без
  ёмкости и в старом интерфейсе блока нет. Контракт результата и ядро не менялись.
