- Интерфейс: поле «Режим шага» для онлайн-источников. «Фиксированный» (по
  умолчанию) отправляет `source-request.v3` без изменений; «Авто» отправляет
  `source-request.v4` с `step_mode: auto`, не требует кратности запаса и
  простоя шагу и не ограничивает явное окно 100 000 ячеек на заявленном шаге
  (ADR 0014). Секция source acquisition показывает `Step origin`,
  `Requested step`, `Series × cells`, при огрублении `Applied step` и
  предупреждение `RESOLUTION_REDUCED` с рядами и агрегациями. Применённый шаг
  сводка публикует только внутри предупреждения, без него строки нет. Серверный
  контракт не менялся; число рядов профиля интерфейсу неизвестно, отказ
  `AUTO_STEP_*` приходит после запуска как диагноз задания. Запуск пары плеч
  при режиме «Авто» заблокирован: пара требует общего явного шага.
