- Windows-скрипт `bin\ltv.bat` из дистрибутива больше не падает при длинном
  пути установки. Раньше скрипт перечислял все jar-файлы в одной командной
  строке, и при пути около 125 символов и длиннее `cmd.exe` отвечал «The input
  line is too long» или «The syntax of the command is incorrect» (лимит
  командной строки 8191 символ). Теперь classpath задан как `%APP_HOME%\lib\*`
  (проверено на пути 205 символов с пробелами и кириллицей: `analyze` и `ui`
  работают). Linux-скрипт `bin/ltv`, формат вывода, коды выхода, API и состав
  `lib/` не менялись. Побочное следствие: любой дополнительный jar, положенный
  в `lib`, попадает в classpath.
