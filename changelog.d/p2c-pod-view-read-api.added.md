- Чтение pod-view по API (платформа, P2c): `GET /api/runs/{runId}/analyses/{analysisId}/pod-view`
  отдаёт метаданные (сетка, `coverage`, список сервисов с числом подов и строк,
  хэши), а `.../pod-view/values?service=...` отдаёт строки сервиса страницами с
  курсором `after`/`next_after`, фильтром `metric` и окном `from_ms`/`to_ms` по
  границам колонок. Каждый запрос сверяет SHA-256 файла: подмена байт при том же
  размере даёт `500 CORRUPT_POD_VIEW`. Маршруты приватные и только на чтение;
  схемы, результат анализа и вердикт не менялись, экраны и серверной статистики
  окна нет. Предел страницы 100 000 ячеек при текущих пределах файла недостижим
  и страхует их будущее повышение.
