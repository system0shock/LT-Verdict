- Вкладка «История» (срез R8 истории релизов): профиль предыдущего релиза серии
  подставляется в форму сохранения и требует явной отметки «Условия теста
  соответствуют заявленному профилю» (пустой профиль сохраняется без неё), у
  релиза с другим профилем стоит знак «другой профиль», предыдущий релиз с тем
  же заявленным профилем отмечен «Предлагаемый baseline» (автоматически не
  выбирается), статистический baseline объясняет, сколько релизов не хватает, и
  открывает вкладку «Сравнение»; над таблицей график p95 по релизам, где вердикт
  дан формой точки и текстом; действие «Перепривязать анализ» заменяет анализ
  релиза пересчитанным анализом того же прогона (путь после смены правил
  анализа; для релиза с несколькими плечами недоступно). API и серверные
  контракты не менялись.
