- Запуск пары плеч на вкладке «Новый анализ» (платформа, срез P1d). Раздел
  «Пара плеч» (переключатель выключен по умолчанию) принимает два набора профилей
  онлайн-источников, по одному на плечо. Файл нагрузки загружается один раз, на
  каждое плечо создаётся своё задание с тем же `run_id` и одним `source-request.v3`
  (общие окно и явный шаг, различаются только `profile_ids`); задания идут по
  очереди. Запуск блокируют пустое плечо, профиль без `arm`, разные метки в одном
  плече и совпадающие метки плеч; общего вердикта плеч нет. `GET /api/sources`
  аддитивно отдаёт `arm` профилей, объявивших плечо. Идентификатор анализа, ядро,
  схемы и ключ сопоставимости не менялись. Ограничения: ИИ-разбор при запуске пары
  и файловые снимки на плечо не поддерживаются, режим шага `auto` в новой
  оболочке ещё не выбирается (срез A-S5 в `main` не влит).
