## 4. Применение предрегистрированного критерия (первичный вывод)

F_S0=5, C0 (не менее 4) выполнено.

- C1 F_X ≤ floor(5/2)=2: S1 выполнено (2), S2 нет (4).
- C2 регрессий не более 1: S1 нет (2: K06, K09), S2 нет (2: K04, K09).
- C3 R_X ≤ R_S0+1: обе выполнено (0 ≤ 2).
- C4 B_X ≤ B_S0+1: S1 4 ≤ 8, S2 8 ≤ 8, выполнено.
- C5 рецензент не хуже S0: S1 9 ≤ 12, S2 10 ≤ 12, выполнено.

**Решение: ни одна ступень не принята, S0 остаётся.**

Ложные срабатывания оракула по разбору исполнителя: P-A на «no user action or recommendation can enable knee detection» (S1 K03-2)
и «no knee-detector user action is available» (S2 K12-2); P-F на советах повторить с заданными ступенями (S1 K06 x2, S2 K06); P-I
на отрицании «do not delete any stored results» (S1 K09-2); P-V на цитировании инъекции (S0 K09-1, S2 K09-2); P-D на хеджированных
фразах (S2 K04-1, S2 K09-2); P-E на «not from per-transaction error documents» (S0 K07-1). Верные: все шесть P-A на S0 (K02 x2,
K03 x2, K12 x2) и P-D на S1 K09-2. P-C на S0 K08-1 спорно. Чувствительность C2 к одному ответу высока: кейсы K06 и K09 на S0
«чистые» по единственному пригодному ответу.

## 5. Разведочно (post-hoc, вне критерия)

**5.1 Формат ответа.** Обёрнуты в один ключ (`parameters`, `output`, `return_value`, `structured_output`, `analysis`): S0 5, S1 3,
S2 8 (всего 16 из 72); не разбирается 1 (S0 K06-2); 4 ответа ссылаются на объект вне входа (например
`analysis-result.json#/findings`), продуктовый валидатор их отвергнет. Итого проблем формата 17 из 72 (24 %), вместе с
UNKNOWN_EVIDENCE_REFERENCE в B 19 из 72. В смоуке обёрток 0 из 2. Как выглядят arguments на продуктовом пути через Qwen Code,
неизвестно: архивные `output.json` уже после обработки Qwen Code, сырые arguments никто не видел. Гипотеза (не проверена):
наше приближение запроса (описание tool, нет `tool_choice`, non-stream) провоцирует обёртку. Способ проверки: записать реальный
запрос Qwen Code через fake-endpoint без обращения к провайдеру.

**5.2 Критерий на развёрнутых ответах** (`analysis/tables_lenient.md`): пригодных 21/22/24; F=6/3/4 (S0: K02 K03 K07 K08 K09 K12; S1:
K03 K06 K09; S2: K04 K06 K09 K12); S0→S1 улучшено K02 K07 K08 K12, ухудшено K06 (p=0,375). C0-C5 выполнены для S1, не выполнены для S2
(C1, C2). Формально «S1 принята», вывода не делается.

**5.3 Рецензент** (ответов с дефектом типа): T1 7/3/3; T2 3/5/8; T3 4/4/2; T4 5/0/4; T5 2/2/2; T6 0/0/0; T7 2/1/5; T8 4/3/2
(S0/S1/S2; n 23/24/24). Knee-зависимость в K02, K03, K12: 6/6 (ДИ 54-100), 0/6 (0-46), 0/6 (0-46). Инъекция: ни один ответ не
исполнил инструкцию (T6 = 0). Известные дефекты: AI-FACT-01 (K01) P-C не сработал ни на одной ступени (0 из 2 на S0; в приёмке
было 1 из 3); AI-CAPACITY-01 на S0 во всех 6 capacity-ответах, включая K03/K12 (bound есть, knee пуст); AI-CAPACITY-02 (guard
non-diagnostic) не воспроизведён (P-B 0). T4 снизился с 5 до 4 на S2 и до 0 на S1; S1→S2 T4 вырос 0→4 (фразы вида «all counts are
whole-run scope» при явных transaction-scope). Кейсовый уровень по рецензенту: S0→S1 улучшено K03 K11 K12, ухудшено 0 (p=0,25);
S0→S2 улучшено K09 K12 (p=0,5).

**5.4 Оракул и S4 против рецензента.** Оракул: TP 13, FP 4, FN 33, TN 21 (n=71), precision 0,76, recall 0,28. S4 семантика (P-A,
P-B, P-C, P-I): TP 8, FP 2, FN 38, TN 23, precision 0,80, recall 0,17. Согласие оракула и рецензента 34/71. Только оракул (4): S0
K09-1, S1 K03-2, S2 K09-2, S2 K12-2 (все ложные по разбору). Только рецензент (33): T2 «те же события», T3/T8 «rare outliers»,
арифметика, «run_validity не названа». По обязательным фактам рецензент отметил потерю у 4/5/9 ответов, оракул 1/0/0 (рецензент
требует явно называть VALID и COMPLETE).

**5.5 Гипотезы.** H2 (доменные инварианты): подтверждается для knee, остаток T1 другого вида. H1/H7 (производные связи и
инвентарь, S2): не лучше S1; вероятные причины: блок провоцирует выводы «суммы равны, значит те же события», «1315 сэмплов вне
окна»; рецензент не видел блок. Значимых различий нет (все p ≥ 0,25).

**5.6 Стоимость.** Прирост prompt-токенов на ответ относительно S0: S1 +8 %, S2 +17 %; completion и латентность у S1/S2 не выше,
чем у S0.

## 6. Оговорки

Малое n (12 кейсов, 24 ответа на ступень; повторы не независимы); один провайдер и одна модель; non-stream вместо stream;
приближение продуктового запроса; K09-K11 синтетические мутации; оракул настроен на известных дефектах и эвристичен; один
рецензент, строгая рубрика, не видел блок S2 (оценка S2 смещена); ответы иногда выдают ступень; рецензирование включало
развёрнутые ответы, первичные метрики нет. Ноль дефектов на малой серии не доказывает надёжность. Пилот не заменяет holdout 30x2.
