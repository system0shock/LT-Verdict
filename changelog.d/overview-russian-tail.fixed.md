- «Обзор» новой оболочки (`?shell=new`, по умолчанию) больше не заканчивается английским
  хвостом: статус задачи («Готово», «Анализ идёт», «n из m байт», «Отменить анализ»,
  «Очередь занята») и ссылки скачивания («Скачать JSON», «Скачать снимок ресурсов» и
  остальные) по-русски; панель «Сохранённая аналитика» (заголовок, поля, кнопки, ссылки
  экспорта и подсказки) тоже по-русски. Таблицы под кнопкой «Обновить аналитику» и блок
  «Grafana evidence» остаются английскими: у профиля Grafana в API нет UID дашборда и
  панели, поэтому значений по умолчанию в нём нет (отдельный срез с изменением профиля).
  Прежний интерфейс, API, ядро и схемы не менялись.
