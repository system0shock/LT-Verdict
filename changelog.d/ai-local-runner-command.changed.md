  именем команды (`gigacode`, `qwen`, `npx`), которое запуск разрешает через

  `LT_VERDICT_AI_LOCAL_QWEN_PREFIX_ARGS` ставит токены перед флагами CLI

  работают без изменений; режим по умолчанию (Docker) не менялся.
