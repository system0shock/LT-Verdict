- Локальный режим раннера ИИ без Docker (ADR 0027, Proposed). Включается
  переменной `LT_VERDICT_AI_RUNNER_MODE=local`: продукт запускает через `bash`
  скрипт `tools/advisory_ai_runtime_local.sh`, а тот запускает локальный CLI
  формата Qwen Code (например, форк GigaCode) процессом, без relay и контейнеров,
  с теми же аргументами, что в контейнерном пути. CLI ходит к модели по
  собственной конфигурации и авторизации оператора; оператор закрепляет SHA-256
  файла CLI (`LT_VERDICT_AI_LOCAL_QWEN_CMD`, `LT_VERDICT_AI_LOCAL_QWEN_SHA256`),
  слаг модели берётся из файла конфигурации моделей (обязателен в этом режиме,
  блок `endpoint` игнорируется), нужные CLI переменные окружения оператор называет
  в `LT_VERDICT_AI_LOCAL_PASSTHROUGH_ENV`. Без переменной режим не включается,
  путь Docker не менялся. Публичный контракт `ai-advice.v1`: у совета режима
  direct `endpoint_host` равен `cli-builtin`, `provider_requests` отсутствует,
  `runner_version` и `runner_artifact_sha256` берутся из CLI и закрепления
  оператора (схема принимает шаблоны вместо констант только для такого совета;
  прежние советы и контейнерный путь читаются как раньше). Формат `ai-models.v1`
  не менялся. Ограничения: нет сетевой изоляции CLI, relay, подсчёта запросов и
  повтора по схеме; не проверен настоящий GigaCode (только Qwen Code 0.21.1 на
  локальной заглушке провайдера).
