- Приватные маршруты истории релизов `GET`/`POST /api/releases` и
  `GET`/`PUT`/`DELETE /api/releases/<release-id>` (ADR 0019, срез R3): запись
  релиза создаётся и заменяется по настоящим документам сохранённых анализов
  (SHA-256 результата по манифесту, предел 64 MiB, `started_at` из `run.json`,
  плечи), список полный и постраничный, новые первыми, с `series_summary` и
  учётом повреждённых записей; в ответе вычисляемые `analysis_state`,
  `baseline_eligible`, `ineligible_reasons`. Ответ `422 RELEASE_LIMIT_REACHED`
  несёт необязательное поле `error.limit`, в остальных ошибках его нет.
  Публичные схемы, identity анализа и интерфейс не менялись; формат записи
  приватный.
