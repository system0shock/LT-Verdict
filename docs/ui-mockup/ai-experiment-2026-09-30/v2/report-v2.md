## 2. Захват: чем запрос Qwen Code отличается от v1

| Параметр | v1 | Qwen Code 0.21.1 |
| --- | --- | --- |
| temperature | не задан | 0 |
| max_tokens | не задан | 64000 (relay удаляет) |
| stream | false | true + include_usage |
| tool_choice | не задан | не задан |
| описание tool | короткое «Return the final structured output...» | длинное: единственный способ выдать результат, первый вызов с валидными аргументами завершает сессию, аргументы обязаны соответствовать схеме, при ошибке можно повторить |
| schema | с `$schema`, `$id` | без них |
| system | `system-prompt.md` | то же байт в байт |
| user | evidence JSON | три блока `system-reminder` (дата, ОС, cwd, список каталога) + evidence |

Qwen проверяет аргументы tool по схеме локально (`additionalProperties:false`) и при ошибке просит повторить; в продукте второй
запрос блокирует relay, запуск завершается `error_during_execution`. Объясняет ли это обёртки v1: частично; с продуктовыми
параметрами в пилоте обёрток 0 из 72, в смоуке одна. Различие смешивает пять изменений, данные раунда их не разделяют.

## 7. Оговорки

Малое n; при temperature 0 повторы почти не независимы; одна модель и один провайдер; хост без Docker (дата, ОС, cwd отличаются);
оракул эвристичен; рецензенты — модели, согласие умеренное, рубрика строгая; блок S2 выдаёт ступень цитатами; нулевой сбой формата
на 72 запусках не гарантирует отсутствие обёрток (верхняя граница около 7 % при 1 из 74).

## 8. Следующий шаг и что нужно от владельца

1. Решение по формату: продуктовый запрос снимает основную часть обёрток, но не все; нужен ли повторный запрос при ошибке схемы
   (сейчас relay блокирует второй запрос; ADR 0010 требует одного).
2. S1 как кандидат prompt v2 для узкого контракта (knee) подтверждён и на v1, и на v2; общий дефицит качества (T2, T3, T7) не закрывает;
   нужны holdout 30 × 2 и оракул v2.
3. Другие модели (glm-5.3, qwen3.8-max) через тот же relay: 48 запросов; остаток раунда 26, общий 152; для holdout новое разрешение.
4. Человек-рецензент на подвыборке (согласие моделей 0,44), расширение рубрики по T2/T7.
5. S3 не запускать (нет остаточного дефицита данных; ADR 0010 запрещает tool calls).
