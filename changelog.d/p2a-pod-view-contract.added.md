- Контракт `pod-view.v1` и его проверка в ядре (платформа, срез P2a; ADR 0020):
  диагностическая проекция подов одного плеча для будущей тепловой карты.
  Добавлены JSON Schema `docs/contracts/pod-view/v1/pod-view.schema.json` с
  примерами и руководство `docs/user/pod-view.md`. Ядро проверяет вход без
  усечения (пределы 256 подов, 2 560 строк, 240 колонок, 64 сервиса, 4
  контейнера на под, файл 12 MiB, токен значения 12 байт без экспоненты) и
  канонизирует его с хэшем, не зависящим от порядка ключей, строк и подов.
  Коды ошибок: `POD_VIEW_INVALID`, `POD_VIEW_LIMIT_EXCEEDED`,
  `POD_VIEW_DUPLICATE_ROW`, `POD_VIEW_UNKNOWN_POD`. Файл пока нельзя подать в
  анализ: вход job, хранение, API и производитель идут отдельными срезами
  (P2b-P2e), поэтому результат анализа, identity, API и интерфейс не менялись.
  Пределы предварительные до замера.
