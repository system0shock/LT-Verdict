  «Предложить стадии» с редактируемым JSON в новой оболочке UI (`?shell=new`,

  байты при совпадении; UI загружает файл один раз, показывает уверенность,
  предупреждения и участки D14 и требует явного подтверждения запуском без

  `analysis_id`, `identity` и схемы не менялись; константы метода предложения не
