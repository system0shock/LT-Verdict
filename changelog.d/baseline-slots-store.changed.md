- Хранилище baseline держит активный baseline по паре `(series, arm)` (ADR 0019,
  срез B1): слоты в `<data>/baselines/<sha256 канонического {arm, series}>.json`
  (до 64, формат `local-baseline.v1` не менялся), плечо берётся из
  `identity.resource_arm` анализа baseline. Прежний `baseline.json` читается без
  миграции как legacy-слот и затеняется слотом того же ключа. Безадресная очистка
  `DELETE /api/baseline` по-прежнему снимает legacy-baseline, но удаляет только
  записи подтверждения условий его ссылки, не используемой слотами (раньше все);
  записей условий не более 4 096. Маршруты, ответы API и интерфейс не менялись:
  выбор слота в comparison и адресное удаление появятся в срезе B2.
