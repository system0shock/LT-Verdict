  выбора baseline русскими фразами по кодам `BASELINE_CANDIDATE_INVALID`,

  отклонений строку профиля условий релизов пары (совпадает или различается с
  перечнем полей). Прежний интерфейс остаётся английским: кнопка доступна, отказ
  показан серверным сообщением. API и серверные контракты не менялись.
