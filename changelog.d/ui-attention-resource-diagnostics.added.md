- «Требует внимания» на «Обзоре» новой оболочки показывает срабатывания
  диагностических правил ресурсов (`effect: diagnostic`, статус `FAIL`:
  например `downstream-slow`, `db-saturated`, ЦП) с пометкой «диагностика,
  не причина». Кнопка «Открыть глубокий анализ» ведёт на вкладку «Глубокий
  анализ» (фокус на заголовке), где ряды непройденных правил выбраны первыми.
  Интерфейс не пересчитывает вердикт, счётчики и причины отсутствия вердикта;
  данные, API и серверные контракты не менялись. Ограничение: диагностическое
  правило генератора в анализе ёмкости (guard) тоже получает такой пункт
  рядом с причиной `CAPACITY_GUARD_FAILED`, потому что результат не выводит
  идентификаторы guard.
