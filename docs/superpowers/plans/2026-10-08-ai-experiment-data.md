## Rulings

- **R-1. Решение 2026-10-04 «эксперимент не коммитим» (ADR 0021, вопрос 10) заменено.** Перечень
  2026-10-08 (согласован владельцем) включает W1.4. Позднее решение владельца побеждает.
  Цена ошибки: если владелец имел в виду иное, PR закрывается без последствий для кода.
  Строки ADR 0021 про «вне git» (около 26-33, 942-983, 1176, 1441) устаревают после слияния; ADR не
  правится (запрет брифа), строки перечислены в отчёте.
- **R-2. «Пилот v2» читается как серия v2 (headless Qwen Code, `preregistration-v2.md`), а не каталог
  `pilot/` (ADR 0024).** Каталог `pilot/` не включается (приманки секретов, сторонний код, цифры ADR 0021
  не питает). Цена ошибки: если нужен и он, добавляется отдельным PR без пересмотра остального.
- **R-3. Сырые потоки.** `v2/runs_raw` включается как `tar.gz` (3,6 МБ): без него не пересчитать долю
  обёрнутых аргументов (v1 16 из 72 против v2 0 из 72, ADR раздел 3). `v3/runs_raw`, `holdout/runs_raw`
  не включаются (цифры ADR 0021 от них не зависят, итоговые P1-P5 пересчитываются из разобранных ответов
  и рецензий); их sha256 перечислены в манифесте, чтобы любой сверил архив владельца. Цена ошибки: нужный
  сырой поток недоступен из git; восстановление из архива владельца.
- **R-4. Секреты не вычищаются правкой, а исключаются файлами.** Правка данных ломает хэши и тезис
  «после просмотра ответов ничего не менялось». Результаты скана приложены в отчёт.
- **R-5. Срез харнесса вместо ссылки на локальную ветку.** Ветки харнесса не на origin; пин SHA без
  копии не даёт воспроизведения «из `origin/main`». Срез ограничен модулями анализа (около 1400 строк),
  копия `git archive 264a340` без правок, не заменяет будущий PR с `tools/ai-experiment`.
  Цена ошибки: дублирование кода при будущем влитии харнесса; срез удаляется тем же PR.
- **R-6. Холдаут пересчитывается независимым stdlib-кодом (рецензии + ключи), а не `holdout_eval.py`.**
  Скрипт оценки зависит от раннера и `codex exec`, а его версия в ветке отличается от зафиксированной
  в `DEFINITIONS_COMMITTED.txt`. Показатели P1 и P2 из отчёта холдаута пересчитываются независимо; P3, P4
  как «нужен харнесс @bc1d6e4 (локальная ветка)».

## Публичный контракт `recompute_adr0021.py`

- Запуск: `python docs/ai-experiment/recompute_adr0021.py [--data-dir <каталог данных>]`; по умолчанию
  каталог данных рядом: `docs/ui-mockup/ai-experiment-2026-09-30`.
- Вывод: строка на проверку `OK|FAIL <id> <описание> ожидалось=<...> получено=<...>` и итог.
- Код выхода: 0 все проверки OK; 1 есть расхождение; 2 нет входных файлов.
- Только стандартная библиотека; данные не пишет.

## Критерии приёмки

1. `python docs/ai-experiment/recompute_adr0021.py` на чистой выгрузке коммита: все проверки OK.
2. Хэши `PREREG_SHA256.txt`, `v2/PREREG_V2_SHA256.txt`, `v3/PREREG_V3_SHA256.txt`,
   `holdout/PREREG_HOLDOUT_SHA256.txt`, `holdout/PLAN_HOLDOUT_SHA256.txt` и `DEFINITIONS_COMMITTED.txt`
   сходятся с блобами из коммита (`git show HEAD:<путь>`), а каждый скопированный файл побайтно равен источнику.
3. `gitleaks detect --no-git` по каталогам PR: без находок кроме внесённых в allowlist canary-строк;
   regex-скан (ключи, Authorization, Bearer, `sk-`, JWT, email, приватные IP, `.ts.net`, пути
   пользователя) просмотрен, находки объяснены.
4. Размер PR: не более ~30 МБ.
5. Замечания Astra (2026-10-08), принятые: (а) `-text` рекурсивно (`ai-experiment-2026-09-30/** -text`) и до первого
   staging; байты хэшируются напрямую, без перенаправления PowerShell; сверка источник -> блоб -> свежая выгрузка
   с `autocrlf=true`; (б) `.gitleaks.toml` с `useDefault = true`, исключения только по конкретным canary-строкам и
   файлам; распакованное содержимое `runs_raw.tar.gz` сканируется gitleaks и regex до упаковки, вложенных архивов
   нет; в отчёте значения не печатаются; (в) проверки повторяют CI: markdownlint по `**/*.md` без игнорируемых
   путей, lychee по `./**/*.md` и `./**/*.html` локальными ссылками; (г) скрипт запускается из чистой выгрузки
   коммита и даёт ненулевой код на отсутствующем, повреждённом и изменённом входе; пропуска проверок нет (все
   реализованные проверки обязательны, невоспроизводимое перечислено в README как «нужен харнесс», в скрипт не
   входит); (д) замкнутый перечень проверяемых чисел задан в README и в скрипте.
6. `markdownlint-cli2` по изменённым `.md`, проверка ссылок README.
