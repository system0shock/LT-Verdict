- Плечо и хэш снимка в списке анализов запуска (платформа, срез P4a).
  Элемент `GET /api/runs/{runId}/analyses` получает необязательные поля
  `resource_arm` (плечо из метки `arm` снимка ресурсов) и
  `resource_snapshot_sha256` (семантический хэш снимка): значения одноимённых
  полей identity анализа. Поле отсутствует, если его нет в identity; для анализов
  без снимка ответ побайтно прежний. Результат анализа, identity и `analysis_id`
  не менялись.
