## Ruling'и

- **Ruling: руководство одним разделом в `slice-1-local-analysis.md`, а не отдельным
  `docs/user/load-stages.md`.** Так указал поручитель PR D; рядом раздел про снимок ресурсов
  (другой источник окон), CLI и таблица ошибок API. Цена ошибки: файл длиннее; вынос в
  отдельный файл потом механический.
- **Ruling: все формулировки сверены запуском `ltv analyze` на `fixtures/stages/ramp-steady-rampdown.jtl`
  и чтением кода, не по ADR.** Там, где ADR и код расходятся (junit у `INVALID`, список кодов
  валидатора), в руководстве описан код, расхождения записаны в отчёт. Цена ошибки: руководство
  устареет вместе с кодом, как любая документация.
